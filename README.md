# Gym Workout Logger

Local-first iPhone gym logger. Weekly program, lock it, log weight × reps, and keep heaviest sets on this device. No accounts, no backend, no cloud sync.

Live: https://vinboy88.github.io/Gym-workout-logger/

## Run locally

```bash
npm i
npm run dev
```

Open http://localhost:5173/Gym-workout-logger/ (Vite `base` is `/Gym-workout-logger/`).

## Build

```bash
npm run build
npm run preview
```

Preview also uses `/Gym-workout-logger/`.

## Phone loop

1. **Program** — seed days (Leg day, Upper body, Push) and exercises. Edit while unlocked.
2. **Lock** — program stays fixed until you explicitly unlock.
3. **Log** — record weight + reps against the locked program.
4. Every exercise shows **heaviest so far** (max weight, then reps) in small muted text.
5. **Settings** — export full backup JSON; import/restore replaces local IndexedDB data.

## PWA (iPhone Safari)

1. Open the live Pages URL (or a local preview) in Safari.
2. Share → **Add to Home Screen**.
3. Launch from the home screen for standalone, offline-capable logging.

The service worker and web app manifest are generated by `vite-plugin-pwa`.

## GitHub Pages

Push to `main` runs `.github/workflows/pages.yml` (build + deploy). First time, set the repo Pages source to **GitHub Actions** if the site 404s:

Repo **Settings → Pages → Source: GitHub Actions**.
